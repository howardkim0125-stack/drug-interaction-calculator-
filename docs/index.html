1어떤 약을 함께 먹나요?

쉼표나 줄바꿈으로 나눠 적어요. 용량은 안 적어도 돼요 — 허가사항의 성인 1회 권장 용량을 기준으로 계산해요. 다른 용량이면 이름 옆에 적어요(예: 이부프로펜 400mg).

    사용법

      무엇을 계산하나요?

      여러 약을 함께 먹을 때 약끼리 주는 영향을 수학 식으로 계산해요.

      • 혈중 농도 변화: 한 약이 다른 약을 분해하는 효소(CYP)를 막거나 늘리면, 그 약의 평균 농도가 몇 배로 바뀌어요.
      • 효과의 겹침: 같은 곳에 작용하거나 같은 효과로 이어지는 약끼리 효과가 합쳐져요.

      계산은 이 기기 안에서만 하고, 입력한 내용은 어디에도 보내지 않아요.

      수학 탐구 모델의 결과이며 실제 복약 판단이 아니다.

      1. 약 이름 넣고 AI에게 묻기

      1. 「상호작용 확인」 첫 칸에 약 이름을 적어요. 용량은 안 적어도 돼요(성인 권장 용량 기준).
      2. 「AI에게 물어볼 글 복사」를 눌러요.
      3. ChatGPT·Claude·Gemini 같은 AI 채팅에 붙여 넣고 보내요.

      AI는 숫자를 지어내지 않고, 출처를 찾은 값만 넣도록 지시받아요. 그래도 AI가 준 숫자는 source의 문서에서 직접 확인하세요.

      자료 출처와 추측 모드

      AI에게 보내는 글에는 공신력 있는 자료 출처 목록(DailyMed 허가 라벨, FDA 상호작용 표, 의약품안전나라, 논문 검색 등)이 들어가요. AI는 여기서 먼저 숫자를 찾아요.

      • 추측 모드 꺼짐(기본): 출처에서 확인한 숫자만 넣어요. 못 찾은 값은 비워 두고, 계산기가 「데이터가 없어서 계산하지 못했다」고 알려 줘요.
      • 추측 모드 켜짐: 정확한 숫자가 없으면 「주로 CYP3A4로 대사된다」, 「강한 억제제」 같은 설명 글을 보고 정해진 기준표에 따라 값을 추정해 넣어요. 추정값은 출처 칸이 「추정:」으로 시작하고, 결과에 추정값 포함으로 표시돼요.

      추정값은 설명 글을 숫자로 어림한 것이라 실제와 다를 수 있어요. 탐구 보고서에는 어떤 값이 추정인지 함께 적으세요.

      2. AI 답 붙여 넣고 계산하기

      1. AI 답 전체를 복사해서 두 번째 칸에 붙여 넣어요(「붙여넣기」 버튼도 돼요).
      2. 「계산하기」를 눌러요.
      3. 빨간 상자는 입력 오류예요. AI에게 오류 문장을 보여 주고 고쳐 달라고 하면 돼요.

      3. 결과 읽기

      • 맨 위 요약: 눈여겨볼 상호작용 몇 건인지, 또는 뚜렷한 상호작용이 없는지 알려 줘요.
      • 데이터 상태: 초록은 계산함, 노랑은 일부 데이터 없음, 빨강은 데이터가 없어서 계산하지 못함. 값이 없는 부분은 숫자를 지어내지 않아요.
      • 혈중 농도 카드: 「가상약B 혈중 농도 ×2.87」처럼 몇 배가 되는지와 원인 효소를 보여 줘요.
      • 효과 카드: 효과가 세짐 약해짐 거의 그대로 중 무엇인지와 원인을 보여 줘요.
      • 약 칩을 눌러 빼거나 넣으면 바로 다시 계산해요.

      숫자로 자세히 보기의 용어

      r혈중 농도 배수. 함께 먹었을 때 그 약의 평균 농도가 몇 배인지 (r = r_간 × r_장). 이면 크게 바뀐 것으로 표시
      B₀상호작용이 없다고 볼 때의 예상 효과 (모든 r = 1, k = 1)
      B_r혈중 농도 변화(r)만 반영한 효과
      B_full함께 먹을 때 계산된 효과 (r과 규칙표의 k 모두 반영)
      R, d
      판정증강(세짐) · 감소(약해짐) · 독립(거의 그대로)
      원인r 기여 = B_r − B₀, k 기여 = B_full − B_r.
      발현threshold가 있는 효과만. 약 하나씩은 기준 미만인데 함께 먹으면 기준 이상이면 발현이고, 「더하기만으로」와 「상호작용 때문에」를 나눠 보여요

      4. AI에게 결과 해석 맡기기

      1. 결과 아래 「AI에게 결과 해석 맡기기 (복사)」를 눌러요. 입력, 데이터 상태, 결과, 계산 과정이 함께 복사돼요.
      2. AI 채팅에 붙여 넣어요.

      AI 답에 계산 결과에 없는 새 숫자나 「먹어도 된다·끊어라」 같은 복약 조언이 나오면 믿지 마세요. 실제 복용은 의사·약사와 상의해야 해요.

      계산 과정은 「계산 과정 보기」에서 식 순서대로 볼 수 있고, 보고서용으로 마크다운 저장이나 「인쇄·PDF 저장」을 할 수 있어요.

      입력 형식 (직접 고치고 싶을 때)

      metabolism분해 효소. f 간에서 그 효소가 맡는 비율, g 장에서 분해되는 비율 (0~1, 각각 합 ≤ 1)
      inhibits억제 효소. s 간, t 장에서 막는 정도 (0 이상 1 미만). 또는 Ki, conc_liver, conc_gut
      induces유도 효소. u: 효소 작용이 (1 + u)배
      actions작용 대상. type은 agonist(작용제)·antagonist(차단제), 세기 c. 또는 e(작용제만), 또는 F, dose, CL, tau + EC50/KB
      dose_ratio기준 용량(권장 용량)의 몇 배인지 (기본 1)
      rules효과마다 up, down, k, threshold, source
      source모든 값에 출처. 가정값은 "virtual" 또는 "가정: 이유"
      dose_basis기준으로 삼은 용량과 출처. {"drug", "dose", "source"}
      missing찾지 못한 값. {"drug", "item", "reason"}

      AI 프롬프트 원문

      입력 만들기 프롬프트 (약 이름 칸이 비어 있는 원본)
      입력 만들기 프롬프트 — 추측 모드 켜짐 (원본)
      결과 해석 프롬프트 (결과 칸이 비어 있는 원본)

      휴대폰·패드에 앱으로 설치하기

      앱스토어 없이 홈 화면에 아이콘을 만들어요. 설치하면 주소창 없이 앱처럼 열리고, 한 번 연 뒤에는 인터넷이 없어도 열려요.

      주소

      아이폰 (Safari) 지금 쓰는 기기

      1. Safari로 위 주소를 열어요.
      2. 화면 아래쪽 공유 버튼(네모에 위쪽 화살표)을 눌러요. 안 보이면 주소창 옆 「⋯」를 누르고 「공유」를 눌러요.
      3. 목록을 아래로 내려 「홈 화면에 추가」를 눌러요.
      4. 오른쪽 위 「추가」를 누르면 홈 화면에 「상호작용 계산기」 아이콘이 생겨요.

      아이패드 (Safari) 지금 쓰는 기기

      1. Safari로 위 주소를 열어요.
      2. 화면 오른쪽 위 주소창 옆의 공유 버튼(네모에 위쪽 화살표)을 눌러요. 안 보이면 「⋯」 → 「공유」.
      3. 「홈 화면에 추가」 → 「추가」를 눌러요.

      아이폰·아이패드의 Chrome에서도 주소창 오른쪽 공유 버튼 → 「홈 화면에 추가」로 할 수 있어요(iOS 16.4 이상). 잘 안 되면 Safari로 하세요.

      안드로이드 휴대폰·태블릿 (Chrome) 지금 쓰는 기기

      1. Chrome으로 위 주소를 열어요.
      2. 오른쪽 위 「⋮」 메뉴 → 「앱 설치」 또는 「홈 화면에 추가」를 눌러요.
      3. 「설치」를 누르면 앱 목록과 홈 화면에 아이콘이 생겨요. 이 화면 위에 「지금 앱 설치」 버튼이 보이면 그걸 눌러도 돼요.

      갤럭시의 삼성 인터넷: 아래쪽 「≡」 → 「현재 페이지 추가」 → 「홈 화면」.

      설치한 뒤에 알아 둘 것

      • 홈 화면 아이콘으로 열면 주소창 없이 앱처럼 열려요.
      • 한 번 열어 둔 뒤에는 인터넷이 없어도 열려요. 인터넷이 되면 새 버전으로 저절로 바뀌어요.
      • 입력한 내용은 그 기기 안에만 저장돼요. 휴대폰과 패드끼리, 그리고 아이폰·아이패드에서는 Safari와 홈 화면 앱끼리도 저장 내용이 따로예요.
      • 지우려면 아이콘을 길게 눌러 「앱 삭제」 또는 「홈 화면에서 제거」를 눌러요.
