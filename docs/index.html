약물 상호작용 계산기

수학 탐구 모델 · 계산은 이 기기 안에서만 하고 입력은 어디에도 보내지 않아요

1약물 집합 붙여 넣기

AI 프롬프트 탭의 「입력 만들기 프롬프트」로 AI가 만든 JSON을 그대로 붙여 넣으세요. 설명 문장이 섞여 있어도 JSON 부분만 찾아 읽어요. 값이 비어 있으면 숫자를 만들지 않고 「데이터가 없어서 계산하지 못했다」고 알려 줘요. 처음이라면 을, 휴대폰·패드에 깔려면 를 보세요.

2함께 먹을 약 고르기 (2개 이상)

3결과

계산 과정 보기 (식에 숫자를 넣은 모습 = 결과)

수학 탐구 모델의 결과이며 실제 복약 판단이 아니다.

AI와 함께 쓰는 방법

  1. 입력 만들기 프롬프트를 복사해 AI(ChatGPT, Claude 등) 채팅에 붙여 넣고, [조사할 약] 칸에 약 이름과 용량을 적어요.
  2. AI가 준 JSON을 계산 탭에 붙여 넣고 「계산하기」를 눌러요. 숫자마다 적힌 출처(source)는 직접 확인하세요.
  3. 결과 아래 「해석 프롬프트 + 결과 복사」를 눌러 AI에 붙여 넣으면 결과를 쉬운 말로 설명받을 수 있어요.

이 앱은 AI를 직접 부르지 않아요. 복사와 붙여 넣기는 직접 해요.

① 입력 만들기 프롬프트

약 이름을 알려 주면 AI가 출처를 붙인 약물 집합(JSON)을 만들어요. 출처를 찾지 못한 값은 빼도록 되어 있어요.

② 결과 해석 프롬프트

계산 탭의 「해석 프롬프트 + 결과 복사」를 쓰면 맨 아래 칸에 결과가 자동으로 들어가요. 여기서 복사하면 결과 칸은 비어 있어요.

규칙표

효과마다 그 효과를 올리는 대상(up), 내리는 대상(down), 대상끼리의 관계 k, 발현 기준 threshold를 적은 표예요. 약물 집합에 rules를 넣으면 그 표를 써요.

판정 기준

쓸 수 있는 효소 이름

튜토리얼

    이 계산기는 무엇인가요?

    여러 경구약을 함께 먹을 때 약끼리 주는 영향을 수학 식으로 계산해요.

    • (가) 평균 농도 변화: 한 약이 다른 약을 분해하는 효소(CYP)를 막거나(억제) 늘리면(유도) 그 약의 평균 농도가 r배가 돼요.
    • (나) 작용의 겹침: 같은 대상에 붙는 약끼리, 또는 같은 효과로 이어지는 서로 다른 대상끼리 작용이 합쳐져요.

    계산은 이 기기 안에서만 하고, 입력한 내용은 어디에도 보내지 않아요.

    수학 탐구 모델의 결과이며 실제 복약 판단이 아니다.

    약 이름·용량
    AI + 입력 만들기 프롬프트
    약물 집합(JSON)
    이 앱: 계산하기
    결과 + 계산 과정

    쉬운 말 해석

    AI는 입력을 만들고 결과를 설명하는 데만 쓰고, 계산은 항상 이 앱이 정해진 식으로 해요.

    약물 집합 만들기

    1. 탭에서 「입력 만들기 프롬프트 복사」를 눌러요.
    2. AI 채팅에 붙여 넣고 [조사할 약] 칸에 약 이름, 1회 용량, 복용 간격을 적어 보내요.
    3. AI가 준 JSON과 「빠진 값」 목록을 확인해요.

    약 이름만 정했다고 계산할 값이 생기지는 않아요. 한 약이 어떤 효소로 분해되고, 다른 약이 그 효소를 막거나 늘린다는 자료가 있어야 계산할 수 있어요. AI가 출처를 찾지 못한 값은 JSON의 missing 목록에 적히고, 계산기는 그 부분을 「데이터 없음」으로 보여 줘요.

    꼭 확인하기: AI가 준 숫자는 source에 적힌 문서에서 직접 확인하세요. 출처가 없는 숫자는 쓰지 마세요. 연습만 하려면 계산 탭의 「예시 넣기」로 가상 약을 쓰면 돼요.

    계산하기

    1. 계산 탭의 입력 칸에 JSON을 붙여 넣거나 「파일 열기」로 .json 파일을 골라요.
    2. 「계산하기」를 누르면 약 목록이 나와요. 함께 먹을 약을 2개 이상 골라요. 고를 때마다 바로 다시 계산해요.
    3. 빨간 상자는 오류예요. 입력을 고쳐야 계산할 수 있어요. 노란 상자는 경고예요. 계산은 됐지만 출처 빈칸, 규칙표에 없는 대상 같은 것을 확인하세요.
    4. 결과 맨 위 데이터 상태 상자를 먼저 봐요. 초록은 계산에 필요한 자료가 있음, 노랑은 일부를 데이터가 없어 계산하지 못함, 빨강은 데이터가 없어서 계산하지 못함이에요. 자료가 없는 부분은 r = 1이나 0 같은 숫자를 결과처럼 보여 주지 않아요.

    결과 읽기

    r함께 먹었을 때 그 약의 평균 농도가 몇 배인지 (r = r_간 × r_장). 이면 「평균 농도 변화」로 표시
    B₀상호작용이 없다고 볼 때의 기준값 (모든 r = 1, k = 1)
    B_r평균 농도 변화(r)만 반영한 값
    B_full실제 계산값 (r과 규칙표의 k 모두 반영)
    R, d
    판정증강 · 감소 · 독립
    원인r 기여 = B_r − B₀, k 기여 = B_full − B_r.
    발현threshold가 있는 효과만. 약 하나씩은 기준 미만인데 함께 먹으면 기준 이상이면 발현이고, 「더하기만으로」와 「상호작용 때문에」를 나눠 보여요

    계산 과정 보기

    결과 아래 「계산 과정 보기」를 펼치면 모든 중간값이 식 순서대로 나와요.

    0. 입력 변환 → 1. 분류 → 2. 효소별 a_간, a_장 → 3. r_간, r_장, r → 4. 대상별 C_ag, C_ant, E_P → 5. 효과별 cᵢ, c_합, 묶음 작용 → 6. B₀, B_r, B_full, 판정 → 7. 발현

    각 줄은 r_간 = 1 ÷ (0.7 × 0.4 + 0.3) = 1.724처럼 식에 숫자를 넣은 모습이에요. 「마크다운 파일로 저장」으로 보고서에 붙일 수 있어요.

    AI로 해석하기

    1. 결과 아래 「해석 프롬프트 + 결과 복사」를 눌러요. 입력, 결과 요약, 계산 과정이 프롬프트 안에 함께 들어가요.
    2. AI 채팅에 붙여 넣어요.

    AI 답에 계산 결과에 없는 새 숫자나 「먹어도 된다·끊어라」 같은 복약 조언이 나오면 믿지 마세요. 실제 복용은 의사·약사와 상의해야 해요.

    입력 형식 한눈에 보기

    metabolism분해 효소. f 간에서 그 효소가 맡는 비율, g 장에서 분해되는 비율 (0~1, 각각 합 ≤ 1)
    inhibits억제 효소. s 간, t 장에서 막는 정도 (0 이상 1 미만). 또는 Ki, conc_liver, conc_gut
    induces유도 효소. u: 효소 작용이 (1 + u)배
    actions작용 대상. type은 agonist(작용제)·antagonist(차단제), 세기 c. 또는 e(작용제만), 또는 F, dose, CL, tau + EC50/KB
    dose_ratio평소 용량의 몇 배인지 (기본 1)
    rules효과마다 up, down, k, threshold, source
    source모든 값에 출처를 적어요. 가정값은 "virtual" 또는 "가정: 이유"
    missing찾지 못한 값 목록. {"drug": "약", "item": "metabolism.CYP3A의 f", "reason": "이유"}

    휴대폰·패드에 앱으로 설치하기

    앱스토어 없이 홈 화면에 아이콘을 만들어요. 설치하면 주소창 없이 앱처럼 열리고, 한 번 연 뒤에는 인터넷이 없어도 열려요.

    주소

    아이폰 (Safari) 지금 쓰는 기기

    1. Safari로 위 주소를 열어요.
    2. 화면 아래쪽 공유 버튼(네모에 위쪽 화살표)을 눌러요. 안 보이면 주소창 옆 「⋯」를 누르고 「공유」를 눌러요.
    3. 목록을 아래로 내려 「홈 화면에 추가」를 눌러요.
    4. 오른쪽 위 「추가」를 누르면 홈 화면에 「상호작용 계산기」 아이콘이 생겨요.

    아이패드 (Safari) 지금 쓰는 기기

    1. Safari로 위 주소를 열어요.
    2. 화면 오른쪽 위 주소창 옆의 공유 버튼(네모에 위쪽 화살표)을 눌러요. 안 보이면 「⋯」 → 「공유」.
    3. 「홈 화면에 추가」 → 「추가」를 눌러요.

    아이폰·아이패드의 Chrome에서도 주소창 오른쪽 공유 버튼 → 「홈 화면에 추가」로 할 수 있어요(iOS 16.4 이상). 잘 안 되면 Safari로 하세요.

    안드로이드 휴대폰·태블릿 (Chrome) 지금 쓰는 기기

    1. Chrome으로 위 주소를 열어요.
    2. 오른쪽 위 「⋮」 메뉴 → 「앱 설치」 또는 「홈 화면에 추가」를 눌러요.
    3. 「설치」를 누르면 앱 목록과 홈 화면에 아이콘이 생겨요. 이 화면 위에 「지금 앱 설치」 버튼이 보이면 그걸 눌러도 돼요.

    갤럭시의 삼성 인터넷: 아래쪽 「≡」 → 「현재 페이지 추가」 → 「홈 화면」.

    설치한 뒤에 알아 둘 것

    • 홈 화면 아이콘으로 열면 주소창 없이 앱처럼 열려요.
    • 한 번 열어 둔 뒤에는 인터넷이 없어도 열려요. 인터넷이 되면 새 버전으로 저절로 바뀌어요.
    • 입력한 약물 집합은 그 기기 안에만 저장돼요. 휴대폰과 패드끼리, 그리고 아이폰·아이패드에서는 Safari와 홈 화면 앱끼리도 저장 내용이 따로예요.
    • 지우려면 아이콘을 길게 눌러 「앱 삭제」 또는 「홈 화면에서 제거」를 눌러요.
